# Leb4Web

Lab4Web

Laporan Praktikum 4: CSS Layout



Langkah-Langkah Praktikum

1. Persiapan Dokumen HTML & CSS Box Element

Penjelasan: Langkah awal dimulai dengan membuat struktur dokumen dasar HTML lab4_box.html dan menambahkan tag semantic <header> dan <section> untuk tempat pembuatan box element.

Screenshot:

![Langkah 1](img/lab4_box.png)


2. Membuat Box Element dan Mengatur Float Property

Penjelasan: Menambahkan elemen <div> dengan class div1, div2, dan div3. Kemudian menerapkan CSS float: left; untuk membuat posisi box element berjajar ke samping secara horizontal.

Screenshot:

![Langkah 2](img/float_property.png)


3. Mengatur Clearfix Element

Penjelasan: Menambahkan div4 dan menggunakan property clear: left; serta float: none; untuk menetralkan efek float dari elemen-elemen sebelumnya sehingga div4 berada di baris baru.

Screenshot:

![Langkah 3](img/clearfix.png)


4. Membuat Kerangka Layout Sederhana (HTML5 Semantics)

Penjelasan: Membuat struktur direktori lab4_layout/ yang berisi home.html dan style.css. Kerangka web dirancang menggunakan HTML5 Semantic Elements seperti <header>, <nav>, <section id="hero">, <section id="wrapper">, <section id="main">, <aside id="sidebar">, dan <footer>.

Screenshot:

![Langkah 4](img/kerangka_layout.png)


5. Menerapkan Styling Header & Navigation Menu

Penjelasan: Menambahkan CSS Reset, styling typography menggunakan Google Fonts (Open Sans), serta mengatur navigasi agar tampil secara horizontal dengan efek hover pada tautan aktif.

Screenshot:

![Langkah 5](img/navigasi.png)


6. Membuat Hero Panel

Penjelasan: Menambahkan bagian hero panel di bawah navigasi sebagai area pengenalan utama (jumbotron) dengan latar belakang khusus, judul, teks deskripsi, dan tombol Call-to-Action (CTA).

Screenshot:

![Langkah 6](img/hero_panel.png)


7. Mengatur Layout Main Content & Sidebar Widget

Penjelasan: Mengatur pembagian area utama (#main) dan sidebar menggunakan float: left; dengan lebar masing-masing 640px dan 260px. Sidebar diisi dengan widget tautan dan widget teks.

Screenshot:

![Langkah 7](img/sidebar_widget.png)


8. Menambahkan Elemen Kartu (Box/Grid) & Artikel

Penjelasan: Menambahkan elemen gambar melingkar (image-circle) beserta deskripsi di area main content, serta membuat artikel blog menggunakan tag <article> yang dilengkapi dengan gambar rata kiri dan rata kanan.

Screenshot:

![Langkah 8](img/content_artikel.png)


9. Mengatur Styling Footer

Penjelasan: Mengatur bagian <footer> di bagian paling bawah halaman web dengan warna latar gelap (#1d1d1d), teks terang, dan property clear: both; agar tata letak tetap konsisten.

Screenshot:

![Langkah 9](img/footer.png)


Tugas & Pertanyaan Praktikum

1. Membuat Halaman About (about.html)

Penjelasan: Membuat tata letak single-layout yang berisi deskripsi profil, portofolio, dan keahlian/skill.

Screenshot:

![Tugas 1 About](img/about.png)


2. Membuat Halaman Contact (kontak.html)

Penjelasan: Membuat halaman kontak yang dilengkapi dengan formulir isian (Nama, Email, Subjek, dan Pesan/Message).

Screenshot:

![Tugas 2 Contact](img/contact.png)
